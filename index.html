Changelog

LATEST

Update 0.3 Beta - Name Change

  • Renamed the game from RNG Game to RNG Roller.
  • Replaced Coins with Money ($) across all rewards, upgrades, and stats.
  • Removed the 40% auto roll penalty — auto rolls now award 100% money.
  • Rebalanced Auto Roll: base interval is now 0.90s (down to 0.30s) and costs $1,000.
  • Added a roll reveal animation and a setting to turn it on or off.
  • Expanded Collection to 10 rarities and increased higher-tier rarity chances.
  • Revamped the Statistics page with highlight cards, categorized metrics, and rarity distribution bars.

Update 0.2 Beta - Improving

  • Auto roll now applies and consumes Focus boosts.
  • Luck gains 0.1× per upgrade with no level cap.
  • Coins and Luck now appear below navigation.
  • Simplified collection odds.
  • Replaced Coin Bonus with Auto Speed.
  • Added On/Off settings buttons.
  • Refreshed the design and separated project files.

Update 0.15 Beta - Convenience

  • Removed the manual roll cooldown.
  • Reduced auto roll cost to 250 coins.
  • Simplified upgrade names and added Settings.

Update 0.1 Beta - RNG 101

  • Introduced rolls, rarities, coins, and upgrades.
  • Added Focus, auto roll, collection, and statistics.
